# MVP Level 1
 Микросервис расчёта кредитных предложений и полного расчёта кредита.

## Запуск локально

1. Создать и активировать виртуальное окружение:
```bash
  python -m venv .venv
```
2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Запустить сервер:
```bash
uvicorn calculator.app.main:app --reload
```
## Документация (Swagger)
После запуска сервера интерактивная документация доступна по адресу:

Swagger UI: http://127.0.0.1:8000/docs


## Тесты и покрытие
Для запуска всех тестов выполните в терминале:

```bash
pytest
```

Процент покрытия: 95.39%

## Реализованные эндпоинты
POST /calculator/offers — расчёт условий кредита. 

POST /calculator/calc — валидация + полный расчет параметров кредита.
